1. Descripción del Proyecto

Este sitio web tiene como objetivo principal posicionar la marca del estudio de arquitectura en el entorno digital. Ofrece a los visitantes una navegación fluida donde pueden explorar proyectos arquitectónicos pasados, conocer la visión de la firma y solicitar cotizaciones o información de contacto.

2. Características Principales

Diseño Responsivo: Adaptado para visualizarse correctamente en computadoras de escritorio, tablets y dispositivos móviles.

Portafolio Interactivo: Galería visual para mostrar planos, renderizados y fotografías de obras finalizadas.

Sección "Sobre Nosotros": Presentación del perfil profesional y la trayectoria arquitectónica.

Formulario de Contacto Directo: Espacio para que potenciales clientes envíen sus requerimientos fácilmente.

3. Tecnologías Utilizadas

HTML5: Estructura semántica del contenido web.

CSS3: Estilos visuales, distribución mediante Flexbox/Grid y efectos de diseño.

Google Fonts & FontAwesome: Tipografía y microiconografía para una estética minimalista.

4. Estructura del Archivo

├── index.html          # Página principal
├── css/
│   └── style.css       # Hoja de estilos globales y componentes
├── assets/
│   ├── images/         # Renderizados, planos y fotos del portafolio
│   └── icons/          # Logotipos e íconos vectoriales
└── README.md           # Documentación del proyecto


5. Instalación y Configuración Local

Para visualizar o modificar este proyecto localmente en tu computadora:

Clona el repositorio o descarga los archivos en tu equipo.

Abre la carpeta del proyecto en tu editor de código (por ejemplo, VS Code).

Abre el archivo index.html en cualquier navegador web moderno (Google Chrome, Firefox, Edge o Safari).

6. Diseño y Metodología

Metodología BEM (Block Element Modifier): CSS estructurado con nombres de clases limpios y fáciles de mantener.

Paleta de Colores: Tonos neutros, sobrios y elegantes orientados a resaltar las imágenes de la arquitectura.

Tipografía: Combinación de fuentes sans-serif modernas para una lectura clara.

7. Integración de Formularios

El sitio incluye la integración de un servicio de formulario externo alojado en la sección de contacto, permitiendo la recepción de mensajes directamente en el correo electrónico sin requerir un backend propio.
